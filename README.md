# go9

iPhoneから遊べる9路盤囲碁。React + TypeScript + Vite。GitHub Pagesで公開します。

## 現在の機能

- 交点をタップして選択、同じ交点をもう一度タップして着手
- 石の取り上げ（アゲハマ）、自殺手禁止、単純コウ禁止
- パス、2回連続パスで終局、対局再開、リセット
- 任意のタイミングでの簡易形勢判断（地＋アゲハマ＋白コミ6.5）

**注意**：日本ルールの死石判定、セキ、ダメ処理、厳密な終局合意、長周期コウは未実装です。形勢表示は確定した勝敗ではありません。AI対局は今後実装します。

## 開発

```bash
npm install
npm test
npm run build
npm run dev
```
